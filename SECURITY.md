# Security

If you find a vulnerability in the banner (for example a way to run script through a configuration value, or a way to make an optional script run without consent), please do not open a public issue. Use GitHub's private vulnerability reporting for this repository ("Security" tab, "Report a vulnerability"), or write to info@socionet.cz.

Published releases are immutable (see README.md), so a fix is always a new version at a new path. Sites have to replace their snippet to get it; we will say so in the release notes.
